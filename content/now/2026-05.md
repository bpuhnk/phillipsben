The month splits down the middle: code in the daylight, the garage after supper.

At work the big one is replacing a thirty-year-old QC station — the kind of project
where the hardest part isn't the WPF or the gauge integrations, it's convincing
everyone the new thing won't *also* be in production for thirty years. Alongside it,
I've been building a tool-use layer for Hermes-Agent: letting the agent call out to a
small, well-defined set of tools — file search, calendar, shop sensors — without
losing the plot.

After dark it moves to the bench. The BLV AM8 got a fine-tune pass — input shaping
dialed, running a 0.16mm benchy against the K1, mostly an excuse to stand in the
garage at 10pm. And there's an ESP32 with mmWave radar going in so the shop lights
know when I'm actually out there. Half the fun is the false-positive log.
