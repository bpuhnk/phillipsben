## What it is.

A desktop control surface for Claude Code sessions — running, branching, and observing
multiple agents at once. Integrates the CLI, the SDK, embedded terminals, and a DevTools
panel for inspecting the model loop in real time.

## Why.

Once you stop thinking of an agent as a chat window and start thinking of it as a
process, you want to see the process. Stack traces. Open files. Active tools. The
same way you'd debug any other long-running program.

## Status.

Active. Public repo on GitHub. Next milestone: multi-agent topology with shared
context windows.
